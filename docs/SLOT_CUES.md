# MOJI SPIN 予告演出（2026-10-21）

作業ブランチ：`feat/slot-preview-effects`。A〜Dの7パターンを表示層に追加。2026-10-21、ユーザーの「公開して」を受領し、検証済みの変更をmainへ反映してGitHub Pagesへ公開する。GAS・Firestoreルール・データ移行は不要。

## 境界と振り分け

`app.js` の `SLOT_CUES` が演出確率と時間の正本。ゲームの抽選・配当は引き続き `MojiSpinEngine`、精算は既存の `createCloud` が担当する。これらのコード、保存するround・receipt、保存呼び出しの順序は変更しない。

通常SPINの全結果を既存処理で一括抽選した直後、中央の確定出目を使って `chooseSlotCue` が表示専用の乱数を1回引く。中央が他の絵柄なら演出抽選をしない。フリーでは予告を実行しない。

|中央|A|B|C|D|なし|
|---|---:|---:|---:|---:|---:|
|BLANK|10.5%|4%|0.5%|0%|85%|
|WILD|35%|30%|10%|5%|20%|

保存応答が別端末の進行中roundへredirectした場合、先に選んだ予告を解除し、保存結果を通常停止で再生する。追加の予告抽選はしない。中断roundの復帰は保存済みの出目を使う。予告の種類は保存しないので、復帰時の予告は変わり得るが出目・配当は変わらない。

## 演出

- A：外周8マスを通常順に停止。中央は絵柄切替を続けて上下左右に3秒間振動し、実際の中央出目で停止。
- B：中央だけ一時BLANKで通常停止。2秒静止後、通常絵柄と同じ大きさの🤡がランダムな画面外の辺から揺れながら2.2秒で飛来。中央に1秒静止し、当たりなら実際のWILDと置き換え、ハズレなら0.9秒で画面外へ退場。
- C：開始時から中央だけ4WILD＋1BLANKの表示専用トラックを循環。中央の停止順で、連続的に6秒かけて減速し、保存済み出目と同じ位置で停止。実際の出目配列には触れない。
- D：全9マスを6秒回転。body直下の固定レイヤーで表示領域全体を瞬時に黒くし、その裏で保存済み9マスを停止。2秒後に巨大🤡が0.45秒で落下。着地と同時に上端の広い範囲から花吹雪を降らせ、着地後2秒待って背景と🤡を1秒でフェードアウト。着地のつぶれ演出でも中心位置を維持する。

保存が遅いときは従来どおり保存結果の確認まで回転を続ける。Dでも未確認の結果を先に停止しないため、応答が6秒を超える場合の回転時間は延長される。

`session.running` の既存制御によりSPIN・遊び方・閉じるは演出中に無効。`resetSlotCueVisuals` と各演出のfinallyでRAF・振動・特殊トラック・全画面レイヤーを解除する。フリーや次回通常SPINへ特殊状態を引き継がない。演出例外時も状態を解除し、既存の保存済みround復帰を使う。残高の表示・TOTAL WIN・finish処理は従来の順序を維持する。
