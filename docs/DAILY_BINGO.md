# デイリービンゴ

街のスロット下の🔢ボタンから開く。自動起動しない。4×4の16マスは `EmojinEngine.EMOJIS` から均等・重複なしで抽選する。縦横各4・斜め2の10ラインへ、下記10特典を重複なしで均等に並べる。

💩はずれ、50/100/500/1,000/2,000/3,000/5,000モジ、孵化＋3、孵化＋10。

モジは街のビーカーSVGに数字を重ね、孵化は🥚に＋X。横ライン特典は左、縦ラインは下、斜めは左上（↘）と左下（↗）に置く。背景は濃紺、アクセントは紫・ミント・金に限定する。

## 抽選とカード更新

- 日本時間0時で日付を切り替え、端末内の本人ごとに1日1回。カードを替えた当日も追加抽選しない。抽選済み日は無効なBINGOボタンを表示し、翌日の案内文は出さない。
- 未済の16マスから毎回1つを均等に選ぶ。はずれマス・重複はない。💩はラインの特典がないという意味で、抽選そのものは必ずマスを埋める。
- BINGO押下時に日付と対象マスを先に保存する。全画面を暗くし、光とともに大きな卵が落下。タップ、または2秒経過で割れる。「タップして」等のヒントは出さない。
- 出た絵文字を見せた後、対象マスだけを明るくする。対象をタップすると済を保存し、アニメーションなしでマス全体を黒にして絵文字を消し、暗幕を解除する。各マスは左・上・右だけにボーダーを持つフラットなデザインで、上の2角だけ丸くする。
- 初めてラインが成立したら、同時に成立した全ラインを強調し、特典を合算して自動で受け取る。💩のみでも成立扱い。精算成功後だけNEW CARDを出し、新しいカードを作成・表示する。
- モジに3,000の切り捨てはない。孵化ポイントは既存ゲージ上限20まで。超過分は他特典へ変換しない。満タン時はその旨を表示する。

## 保存・中断と二重精算防止

`localStorage` の `emojin.dailyBingo.<projectId>.<uid>` にカード、特典配置、済マス、最後の抽選日、演出段階、受け取り結果を保存する。オーナー間で共用しない。カードは日をまたいで維持する。端末・ブラウザーが変わる場合、カードは別になる。

卵・対象マス・報酬待ちのどこで再読み込みしても同じ抽選から復帰する。カードの破損時はエラーを表示し、勝手に新規抽選へ置き換えない。Web Locksとstorageイベントで同じ端末のタブを同期し、対象を確定した後の再抽選を防ぐ。閉じる/背面操作/PWA更新は演出・精算中に進めない。報酬保存に失敗した場合は同じカード・同じラインで再試行し、保存前にNEW CARDへ進ませない。

新規のDB管理コレクションは作らない。成立カードIDを操作IDとし、既存の操作キューとウォレットトランザクションで `wallets/{uid}/operations/bingo-<UUID>` に不変receiptを作る。kind=dailyBingo、cardId、day、成立lines、実付与moji/hatch、atを保存する。既存receiptがあれば再加算しない。通常スピン・draftなど財布の他フィールドは維持する。

カードと日次回数はユーザー合意どおり端末管理であり、端末保存の削除や端末間での日次回数共有はDBでは管理しない。DBのreceiptは同じカードの再送・中断復帰・同時請求の二重精算を防ぐ。

GAS・Firestoreルール変更・データ移行は不要。既存の本人専用wallet/receiptの権限を使う。廃止したデイリーバトルは復活させない。
