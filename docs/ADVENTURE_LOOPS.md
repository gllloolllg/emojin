# エモジンのぼうけん：周回と到達階数（2026-11-16）

## 周回

- 地下10・20・30…階のラスボス撃破後はスコアを確定せず、エンディング → 豪華な宝箱 → 通常能力の置換 → 次の階へ進む。同じ有料プレイを継続し、追加の100モジは消費しない。ゲームオーバー時に最終スコアと到達階数を保存する。中断復帰なし・「にげる」で放棄する既存仕様は維持する。
- 残りHP・元の最大HP・金色HP枠・レベル・経験値・爆弾・スロット・スコアを引き継ぐ。周回開始で回復しない。戦闘後の毒・呪い解除は維持し、新しいボスはチャージなしで生成する。元のマイエモジンを変更しない。
- 地下表示は11・12…と続く。左の10段メーターは各周回内の位置へ戻る。マップは1周目が従来の茶色、2周目が緑、3周目以降が紫。2周目の敵は緑のオーラ、3周目以降は紫のオーラを持つ。チャージ中の強弱も維持する。

周回をL（1から）とし、周回内の階数は ((到達階数−1) % 10) + 1 とする。

| 項目 | 計算 |
|---|---|
| ザコの種類 | 周回内1〜3階=Lv1、4〜7階=Lv2、8〜10階=Lv3 |
| ザコHP | 元の範囲 ＋ (L−1) |
| 中ボス | 周回内5階。HP=8＋2×(L−1) |
| ラスボス | 周回内10階。HP40、必殺技の開始n=L |
| ザコ経験値 | ザコLv＋(L−1)。逃走は0 |
| 中ボス経験値 | 3＋(L−1)。逃走は0 |
| ラスボス経験値 | L−1（1周目0、2周目1、3周目2…） |
| 得点 | すべての既存配点×L |

- 通常の攻撃力・スロット確率・アイテム配置・回復・戦闘処理は変更しない。ザコ10、中ボス20、ラスボス30ターンも同じ。地下15・25…階の中ボス逃走時も次へ進む。
- 移動得点は通算階数で計算し、地下11階到達は11×500×2=11,000点、地下21階は21×500×3=31,500点。ラスボスのハート位置の配点・回復後の再加点にも倍率を掛ける。ザコ戦をラスボスの攻撃得点として数えない。
- 2周目以降のラスボス階へ入る前に、全プレイヤーのレジェンドを件数制限なしで読み、均等に1体を再抽選する。読み取りに失敗したら階数・得点を変更せず再試行する。レジェンド不在時だけ既存の代替ボスを使う。最初のボスは開始receiptのスナップショットを維持する。

## 豪華な宝箱

- エンディングは文字送りで表示し、表示中のタップで全文表示、次のタップで宝箱へ進む。
- 金色の宝箱をタップすると蓋を消し、箱を消して獲得能力を大きく表示する。その後ステータスを表示し、通常5枠だけを白枠で点滅させる。
- ハズレを除く通常生成の重みで1回抽選する。攻撃1:30、攻撃2:22、回復:10、防御:10、カウンター:10（合計82で正規化）。特殊能力は抽選対象外。
- 任意の通常枠をタップすると、能力をその枠へ飛ばして置換する。特殊枠は操作不可。変更しない選択肢はなく、同じ能力の枠も選択できる。二重タップで複数置換しない。
- 宝箱開封は既存の宝箱得点300×その時点の周回倍率。能力獲得だけの追加得点はない。通常の宝箱の中身・確率は変更しない。

## 保存・ランキング

- `floor` を通算の到達階数として既存の個人記録・共有entriesへ保存する。保存時の10階上限だけを外し、正の安全な整数かを検証する。既存の旧クリア結果も引き続き受理する。
- 見出しは「ランク、スコア、なまえ、ステージ」。両タブで「21かい」のように表示し、「かい」は数字の0.5em。スコアは先頭0なしのまま。
- 既存記録に有効なfloorがある場合はその値を使う。floorがない旧記録は表示時だけ10階として扱う。過去データの書き換えはしない。上位10件、同一プレイヤーの複数記録、ランクイン行の一度きりの点滅は維持する。
- 得点イベントのカウンターへその時点の周回倍率を掛けて積算し、既存WEIGHTSとの積でスコアを検証する。保存世代3・collection・wallet/receipt・Firestoreルールの配点式を維持する。既存記録と未送信の旧結果もそのまま扱える。
- GAS・Firestoreルール変更、データ移行、新規必須ファイルは不要。PWAは既存の完全シェル更新を使い、プレイ中の更新延期を維持する。
